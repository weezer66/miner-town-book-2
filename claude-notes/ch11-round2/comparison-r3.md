## Not applied
- **Sonnet: "rook one is illegal".** Sonnet assumed the queen took on g7. The prose has Black push the pawn ("moved a pawn up to blunt the queen's line"), so the queen takes on g6. From there Kh8 is legal, and Qh7#/Qg7# is mate in one. Fable's check agrees.
- **Haiku: "its stone twin" clarification.** The stone set on the table is already the Grandmaster's board.
