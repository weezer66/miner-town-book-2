## 3. Tracker Update Instructions

Update this file daily after execution: [channel_performance_tracker.csv](channel_performance_tracker.csv)

For the row matching each day’s opportunity_name, update these exact fields:
1. last_action_date
   - Set to execution date in YYYY-MM-DD.
2. effort_minutes
   - Replace with actual minutes spent that day.
3. outcome_points
   - Compute with this free-channel weighted formula:
   - outcome_points = (0.2 x clicks) + (2 x saves/upvotes) + (3 x comments/replies) + (0.5 x profile visits) + (4 x list adds) + (5 x ARC requests)
4. efficiency_score
   - Set to outcome_points / effort_minutes (if effort_minutes > 0), rounded to 2 decimals.
5. status
   - Keep as active unless you intentionally retire that channel.
6. notes
   - Append one compact daily log entry:
   - D# YYYY-MM-DD | metrics: clicks=X, saves/upvotes=Y, comments/replies=Z, profile visits=A, list adds=B, ARC requests=C | what worked: ... | risk/policy notes: ...

Recommended weekly hygiene after Day 7:
1. Re-rank channels by updated efficiency_score.
2. Downgrade any channel with repeated policy friction by lowering priority_tier.
3. Promote top 2 performing channels into next week with fresh A/B copy variants.
