## 4. Tracker Update Instructions

### 4A. Update channel_performance_tracker.csv (after each day)

File: channel_performance_tracker.csv

For each executed channel row, update:
1. last_action_date
   - Format: YYYY-MM-DD
2. effort_minutes
   - Set to actual minutes spent on that channel action (split daily minutes across channels when 2 channels are used)
3. outcome_points
   - Use:
   - outcome_points = (0.2 x clicks) + (2 x saves/upvotes) + (3 x comments/replies) + (0.5 x profile visits) + (4 x list adds) + (5 x ARC requests)
4. efficiency_score
   - If effort_minutes > 0: efficiency_score = outcome_points / effort_minutes (round to 2 decimals)
5. status
   - Keep active unless intentionally retired
6. notes
   - Append: D# YYYY-MM-DD | metrics: clicks=X, saves/upvotes=Y, comments/replies=Z, profile visits=A, list adds=B, ARC requests=C | what worked: ... | policy notes: ...
